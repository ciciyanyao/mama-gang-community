# BF类任务开发指南

## 任务概览

本文件夹包含类B（论坛交流）和类F（消息·我的·管理）的待开发任务。

### 类B - 论坛交流（主体）
- **已完成**：B1-B5（帖子信息流、板块切换、详情页、评论、点赞）
- **待开发**：
  - B6: 热门榜（P1）- 按热度取TOP10
  - B7: 置顶帖（P1）- 根据is_top字段置顶展示

### 类F - 消息·我的·管理
- **全部待开发**：
  - F1: 消息列表（按帖子聚合展示）
  - F2: TabBar红点
  - F3: 我的页（我的帖子、我的收藏、设置）
  - F4: 收藏/取消帖子
  - F5: 管理端（admin云函数）
  - F6: 招聘信息（P2可选）
  - F7: 订阅消息/分享（P2可选）

## 开发建议

1. **优先级**：建议先完成P0任务（F1、F5），再完成P1任务（B6、B7、F2、F3、F4）
2. **依赖关系**：F1依赖B的评论功能，F5依赖C的举报功能
3. **云函数部署**：每次修改云函数后需要重新部署
4. **测试数据**：需要在云开发控制台创建相应的集合和测试数据
