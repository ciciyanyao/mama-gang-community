## 任务说明

### F1: 消息列表（P0）
- **目标**：显示用户收到的评论/回复
- **展示方式**：按帖子聚合展示
- **数据来源**：comments集合，按postId聚合
- **依赖**：B的评论功能已完成

### F2: TabBar红点（P1）
- **目标**：有未读消息时显示红点
- **实现方式**：MVP版本进消息页即算已读
- **技术点**：wx.showTabBarRedDot

### F3: 我的页（P1）
- **目标**：用户个人中心
- **功能**：我的帖子、我的收藏、设置
- **页面**：mine页面

### F4: 收藏/取消帖子（P1）
- **目标**：用户可以收藏帖子
- **数据模型**：favorites集合
- **依赖**：帖子详情页

### F5: 管理端（P0）
- **目标**：管理员管理社区
- **功能**：删帖、删评论、处理举报
- **权限**：users.role=2的用户
- **依赖**：C的举报功能

### F6: 招聘信息（P2）
- **目标**：岗位卡片、城市筛选
- **状态**：可选功能
- **数据**：演示静态样例

### F7: 订阅消息/分享（P2）
- **目标**：答辩加分项
- **状态**：可选功能
