# B7: 置顶帖实现指南

## 任务说明

- **优先级**：P1
- **目标**：管理员可置顶重要帖子
- **实现方式**：通过is_top字段控制
- **展示逻辑**：置顶帖始终显示在列表顶部
- **状态字段**：status/is_top

## 实现步骤

### 1. 修改云函数（post/index.js）

修改获取帖子列表的逻辑，优先返回置顶帖：

```javascript
// 修改 handleGetPostList 函数
async function handleGetPostList(event, context) {
  const db = cloud.database();
  const _ = db.command;
  const { category, page = 1, pageSize = 20 } = event;
  
  try {
    let query = db.collection('posts').where({
      status: 1 // 只查询正常状态的帖子
    });
    
    // 按分类筛选
    if (category && category !== 'all') {
      query = query.where({
        category: category
      });
    }
    
    // 分页查询，优先返回置顶帖
    const result = await query
      .orderBy('is_top', 'desc') // 置顶帖排在前面
      .orderBy('create_time', 'desc') // 然后按创建时间倒序
      .skip((page - 1) * pageSize)
      .limit(pageSize)
      .get();
    
    return {
      code: 0,
      message: '获取帖子列表成功',
      data: result.data
    };
  } catch (err) {
    return {
      code: -1,
      message: '获取帖子列表失败',
      error: err.message
    };
  }
}
```

添加设置置顶状态的操作（管理员使用）：

```javascript
// 设置帖子置顶状态
async function handleSetTop(event, context) {
  const db = cloud.database();
  const { postId, isTop } = event;
  
  try {
    // 验证管理员权限
    const { OPENID } = cloud.getWXContext();
    const userResult = await db.collection('users')
      .where({
        _openid: OPENID,
        role: 2 // 管理员角色
      })
      .get();
    
    if (userResult.data.length === 0) {
      return {
        code: -1,
        message: '权限不足，只有管理员可以设置置顶'
      };
    }
    
    // 更新帖子置顶状态
    const result = await db.collection('posts')
      .doc(postId)
      .update({
        data: {
          is_top: isTop
        }
      });
    
    return {
      code: 0,
      message: isTop ? '帖子已置顶' : '帖子已取消置顶',
      data: result
    };
  } catch (err) {
    return {
      code: -1,
      message: '设置置顶失败',
      error: err.message
    };
  }
}
```

在主函数中添加路由：

```javascript
// 在 switch (event.action) 中添加
case 'setTop':
  return await handleSetTop(event, context);
```

### 2. 修改前端页面（index/index.js）

添加置顶标识的显示逻辑：

```javascript
// 在帖子数据处理中添加置顶标识
processPostData(posts) {
  return posts.map(post => {
    return {
      ...post,
      isTop: post.is_top || false,
      topText: post.is_top ? '置顶' : ''
    };
  });
},

// 在获取帖子列表后调用
async loadPosts() {
  try {
    const res = await wx.cloud.callFunction({
      name: 'post',
      data: {
        action: 'list',
        category: this.data.currentCategory,
        page: this.data.page,
        pageSize: this.data.pageSize
      }
    });
    
    if (res.result.code === 0) {
      const posts = this.processPostData(res.result.data);
      this.setData({
        posts: this.data.page === 1 ? posts : [...this.data.posts, ...posts]
      });
    }
  } catch (err) {
    console.error('获取帖子列表失败', err);
  }
}
```

## 数据模型

### posts集合（已有字段）
- `is_top` - 是否置顶（true/false）
- `status` - 状态（1=正常）
- `create_time` - 创建时间

## 验收标准

- ✅ 置顶帖显示在列表顶部
- ✅ 置顶帖有明显标识（"置顶"标签）
- ✅ 非置顶帖正常排序
- ✅ 管理员可以设置置顶状态

## 测试方法

1. 在云开发控制台手动设置is_top=true
2. 验证置顶帖显示在顶部
3. 验证置顶标识显示正确
4. 测试不同分类下的置顶效果

## 注意事项

1. 置顶帖应该在所有分类中都显示在顶部
2. 多个置顶帖时，按创建时间倒序排列
3. 置顶标识应该明显但不喧宾夺主
4. 管理员权限验证要严格

## 优化建议

1. **置顶数量限制**：可以限制最多置顶3-5个帖子
2. **置顶时间**：可以设置置顶有效期
3. **置顶原因**：管理员可以填写置顶原因
4. **置顶通知**：被置顶的帖子作者会收到通知

## 管理员操作指南

### 通过云开发控制台设置置顶
1. 打开云开发控制台
2. 进入数据库 → posts集合
3. 找到要置顶的帖子
4. 修改is_top字段为true
