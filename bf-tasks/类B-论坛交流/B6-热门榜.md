# B6: 热门榜实现指南

## 任务说明

- **优先级**：P1
- **目标**：按热度排序显示TOP10帖子
- **热度计算**：点赞数 + 评论数
- **展示位置**：首页顶部或独立区域

## 实现步骤

### 1. 修改云函数（post/index.js）

添加获取热门帖子的操作：

```javascript
// 在 handleGetPostList 函数中添加按热度排序的逻辑
async function handleGetHotPosts(event, context) {
  const db = cloud.database();
  const _ = db.command;
  
  try {
    // 获取帖子列表，按热度排序（likeCount + commentCount）
    const result = await db.collection('posts')
      .where({
        status: 1 // 只查询正常状态的帖子
      })
      .orderBy('likeCount', 'desc') // 先按点赞数排序
      .orderBy('commentCount', 'desc') // 再按评论数排序
      .limit(10) // 只取前10条
      .get();
    
    return {
      code: 0,
      message: '获取热门帖子成功',
      data: result.data
    };
  } catch (err) {
    return {
      code: -1,
      message: '获取热门帖子失败',
      error: err.message
    };
  }
}
```

在主函数中添加路由：

```javascript
// 在 switch (event.action) 中添加
case 'hot':
  return await handleGetHotPosts(event, context);
```

### 2. 修改前端页面（index/index.js）

添加获取热门帖子的方法：

```javascript
// 获取热门帖子
async loadHotPosts() {
  try {
    const res = await wx.cloud.callFunction({
      name: 'post',
      data: {
        action: 'hot'
      }
    });
    
    if (res.result.code === 0) {
      this.setData({
        hotPosts: res.result.data
      });
    }
  } catch (err) {
    console.error('获取热门帖子失败', err);
  }
},

// 在 onLoad 或 onShow 中调用
onLoad() {
  this.loadHotPosts();
  // ... 其他初始化代码
}
```

- ✅ 点击可跳转到帖子详情

## 测试方法

1. 确保有足够的帖子数据（至少10条）
2. 为一些帖子添加点赞和评论数据
3. 验证热门榜显示正确的TOP10
4. 验证热度计算正确

## 注意事项

1. 如果帖子数量不足10条，显示所有帖子
2. 热度相同时，可以按创建时间排序
3. 可以考虑添加下拉刷新功能
4. 热门榜数据可以缓存，减少云函数调用

## 优化建议

1. **缓存机制**：将热门榜数据缓存到本地，设置过期时间
2. **定时更新**：每天凌晨自动更新热门榜
3. **动画效果**：添加进入动画，提升用户体验
4. **点击反馈**：添加点击效果，如波纹或缩放
